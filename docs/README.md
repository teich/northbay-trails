# North Bay Trails docs

North Bay Trails is an interactive, hand-painted-looking model of seven mountain bike parks in Sonoma and Napa counties (Monte Rio Redwoods, Taylor Mountain, Trione-Annadel, Jack London, Hood Mountain, the PUC forest in Angwin, and Moore Creek), with a checklist for tracking which trails you've ridden. These docs describe what the app is for and how to use it.

- **[What it is](overview.md)**: the intent behind the app and what's on the map
- **[Using the map](using-the-map.md)**: moving around, finding trails, reading a trail card, and tracking what you've ridden
- **[Where the data comes from](data.md)**: sources, what counts as a trail, and the limits

To run it locally, see the [project README](../README.md).
